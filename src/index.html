GitHub Proxy

Release、源码包、Raw 文件与 git clone 加速下载

支持的链接

  • Release 文件 https://github.com/user/repo/releases/download/v1.0.0/app.zip
  • 分支源码 https://github.com/user/repo/archive/refs/heads/main.zip
  • Tag 源码 https://github.com/user/repo/archive/v1.0.0.tar.gz
  • 仓库文件 https://github.com/user/repo/blob/main/README.md
  • Raw https://raw.githubusercontent.com/user/repo/main/README.md
  • Gist https://gist.githubusercontent.com/user/gist-id/raw/file.txt
  • git clone git clone https://github.com/user/repo

在上方输入框粘贴以上任意一种链接即可。链接带不带 https:// 都可以；不支持下载整个文件夹，请使用 git clone。
